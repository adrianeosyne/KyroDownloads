# Kyro for Windows

Download the official Kyro desktop app for **Windows 10 and 11 (x64)**.

[Download Kyro 1.0.0](https://github.com/adrianeosyne/KyroDownloads/releases/download/desktop-v1.0.0/Kyro-Setup-1.0.0-x64.exe) · [Website](https://kyro-chat.cyou/download) · [Release notes](https://github.com/adrianeosyne/KyroDownloads/releases/latest)

Open the installer, choose a folder, and sign in with your Kyro account. Includes desktop and Start menu shortcuts, a dedicated window, microphone/camera consent and a screen-sharing picker. An internet connection is required.

The initial installer is **unsigned**, so Windows may show an unknown publisher or SmartScreen notice. Releases include a SHA-256 checksum. Verify your download using:

```powershell
Get-FileHash .\Kyro-Setup-1.0.0-x64.exe -Algorithm SHA256
```

This public repository contains installers and checksums. Application source is maintained separately. Use **Kyro > Downloads & updates** in the desktop app to find new installers.
